# Glass TV Launcher 0.3.0 beta 2

The second plain-APK beta. Everything below installs as an ordinary app: no root, no Magisk, no system partition.
This beta is about 80 commits past beta 1 and is the first to include the idle Home, the smaller APK, the faster Control
Center and the batch of Home focus, tray and menu fixes landed on 25 October.

## What's new in beta 2

### Smaller and faster

- **The download is 3.28 MB, down from 5.79 MB.** The dex is stored compressed, release builds ship only the two ARM
  ABIs a TV needs, and the repeated AndroidX licence texts were replaced by one set. Nothing was removed from the UI.
- **Control Center opens in 179 ms instead of 282 ms** on the stick (warm, measured frame by frame). The parked panel
  is laid out but not drawn, so it holds no textures while you are on Home.
- **Home draws in bands.** The tray, the app grid and the notice host each draw in their own layer, so moving focus
  across the dock repaints the dock's band instead of the whole 1080p screen. That is most of the felt smoothness work
  in this release.
- **Idle Home is quiet.** After the configured idle delay the dock, grid and shelf fade out and the launcher stops
  animating; any key brings them back, pixel-identically, in the same 250 ms wake. While hidden the app renders 0–1
  frames per 20 s.
- **Hero art is ready before you get there.** A tray app's neighbours are prefetched after a second with no input, the
  hero is cached on disk as WebP (about half the decode cost of PNG), and the scroll-blur ladder is baked once instead
  of before every swap.

### Look and feel

- Notices are one top-left glass card with tvOS's banner shape, not a system Toast or dialog anywhere.
- Now Playing has a square cover with the playing app's icon as a badge, and the source app is named.
- The Now Playing card, Control Center tiles and search results got the spacing and clipping fixes reported on the
  stick.
- Cover Flow's album caption sits clear of the tray arrow; the focused Settings tile no longer crowds the Sleep pill.
- The app-open and app-close transitions use the same short fade, so resuming an app no longer plays the system
  scale-up "genie" before Glass's own animation.

### Fixes

- Focus returns to the tile after an app menu, folder or info card closes; the D-pad no longer goes dead until Home.
- A Glass Pro / Glass OS update can no longer crash-loop Home after a reboot: the system-app install clears the
  package cache and the version code always increases.
- The Amazon Appstore shortcut opens the Appstore's own home instead of the stock Fire OS home.
- The tray and grid are hidden while an app is in front; they no longer draw over the running app.
- Context menus beside a dock tile open above the tile instead of over the Top Shelf.
- The Speed tile, which only ever ran a one-off `am kill-all`, is gone. Saved layouts lose it automatically.
- Root commands share one long-lived shell, so Magisk no longer shows a root toast for every command.
- Two test flakes that used wall-clock assumptions were rewritten on virtual time; CI is green again.

### Performance on the stick

Measured on a Fire TV Stick 4K (2nd gen), release build, on the 25 October master:

| Route | Deadline-missed | p99 | PSS |
|---|---|---|---|
| Dock (D-pad across the tray) | 0.58 % | 24 ms | 124 MB |
| App grid | 0.0 % | 11 ms | 98 MB |
| Idle CPU | 0.4 % | — | — |

The same route on a debug build read p90 22 ms / 5.02 % deadline-missed, which is why this release and the README ask
for a release build when judging smoothness. (The stick had a debug APK on it for a while; that was the lag most people
were feeling.)

## About the name

The launcher is called **VITRE** in the app and its settings from this beta. The Android package
(`dev.glasslauncher`), this repository and the APK file name keep their Glass names for now, so an existing install
updates in place and every old link still resolves. The rename of the repository and the listings follows separately.

## What Glass is

Glass is an open-source, tvOS-inspired home screen for Android TV, Google TV and Fire TV: a glass dock of your apps, a
featured shelf from the source you choose, a Control Center, search, folders, widgets and an optional screensaver, all
driven by a D-pad remote. It runs as an ordinary app. Nothing below needs root.

## Supported devices

| Device | Status |
|---|---|
| Fire TV Stick 4K (2nd gen) | Tested, daily use |
| Other Fire TV devices (Fire OS 7 and newer) | Expected to work, not tested |
| Android TV and Google TV devices (Android 9, API 28, or newer) | Checked on an Android TV emulator: Home, Settings, Search, Control Center, the output picker, Downloads and pairing run without errors, and Fire-only features are hidden. Not yet tested on real hardware |

Needs a TV with a remote (no touch or mouse support). Some Google TV and Chromecast firmware keeps its own launcher in
front, so Glass may not be able to become the default home there.

## Install (plain APK, no root)

1. Download `glass-tv-launcher-v0.3.0-beta.2.apk` from the release page.
2. Install it one of two ways:
   - **On the TV with Downloader:** open the Downloader app, enter the APK's release-page address, and install when
     asked. Allow "Install unknown apps" for Downloader if the TV asks.
   - **From a computer with adb:** enable ADB debugging on the TV, then
     ```bash
     adb connect <tv-ip>:5555
     adb install -r glass-tv-launcher-v0.3.0-beta.2.apk
     ```
3. Open **VITRE** once from the TV's app list (it is the launcher's name in the UI from this beta). The first launch
   shows a Welcome card (select Get Started). It may then show two more cards: "Turn on remote buttons?" and
   "Make VITRE your Home". Select Cancel on both for now; the steps below cover them.
4. Make it your home screen. The launcher's own Settings are not the big Settings tile: select the clock at the top
   right to open Control Center, then choose Launcher Settings (the sliders icon), then Home Button.
   - **Android TV / Google TV:** choose *Make VITRE the Default*, pick VITRE in the dialog Android shows, and select
     *Set as default*.
   - **Fire TV:** Fire OS has no default-launcher picker. Turn on *Home Button Takeover* on the same page, or see the
     README for the adb command. Keep the undo command at hand.
5. Optional one-time permissions (recent apps, Wi-Fi name, screensaver) are listed in the README. Everything works
   without them.

To go back: Settings → Home Button → switch the default home to the stock launcher, then uninstall VITRE.

## What is in this beta

- Dock, folders, rearranging, hiding apps, icon packs and wallpapers (light and dark).
- Featured shelf from Stremio, Netflix, Prime Video, Disney+, Max, Hulu, YouTube or Plex, with an info panel and a
  Seasons view; Resume starts playback in the app (Stremio resumes with no extra press).
- Search across your apps, titles and music, with a full keyboard, a symbols page and forgiving matching.
- Control Center: Wi-Fi, Bluetooth, sleep, audio output picker (including network speakers), Do Not Disturb, Now
  Playing with seek and like, and Remotes and Game Controllers pages with pairing, a live controller tester and button
  mapping.
- A Control Center shortcut on a remote key, and remappable remote and controller buttons.
- Install and update progress on app tiles, and a "View in Store" shortcut.
- Notices that queue one at a time and hold under Do Not Disturb.
- Screen-reader labels on every control, Reduce Motion, Reduce Transparency and large text.
- In-app updates, backup and restore.

## Known limits

- Tested on real hardware only on a Fire TV Stick 4K (2nd gen). Everything else is untested or emulator-tested.
- English only.
- The in-app updater only looks at full releases, so a beta is installed by hand and will not offer itself as an
  update.
- Fire-only features (Alexa and Smart Home tiles, Amazon Appstore shortcuts) are hidden on other devices.
- Features that need root (Continue Watching rows from other apps, memory tuning, system-app mode) appear only on
  rooted devices and are off otherwise. Remote buttons that Fire OS keeps to itself need the optional key-layout
  module and a rooted Fire TV.
- Pairing from Glass needs Bluetooth permission. Where the system does not let Glass scan, the Pair page opens the
  system Bluetooth settings instead.
- The aerial screensaver streams from an undocumented online feed, and streaming availability comes from an unofficial
  endpoint. Either can change or stop working without notice.
- The release is signed with the project's release key; builds from source are signed with a debug key, so you cannot
  install one over the other without uninstalling first.

## Reporting bugs

Open an issue at <https://github.com/AazainKhan/glass-tv-launcher/issues> with:

- your TV or stick model and its Android or Fire OS version,
- the version shown in Settings → About,
- what you did, what you expected and what happened,
- a photo of the screen if it helps.

Security problems: see `SECURITY.md`, and do not post them publicly.
