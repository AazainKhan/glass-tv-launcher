# Glass TV Launcher 0.3.0 beta 1 (draft)

Draft release notes for the first plain-APK beta. Not published. The tag, the GitHub release and the download links are filled in
when it is approved.

## What Glass is

Glass is an open-source, tvOS-inspired home screen for Android TV, Google TV and Fire TV: a glass dock of your apps, a featured
shelf from the source you choose, a Control Center, search, folders, widgets and an optional screensaver, all driven by a D-pad
remote. It runs as an ordinary app. Nothing below needs root.

## Supported devices

| Device | Status |
|---|---|
| Fire TV Stick 4K (2nd gen) | Tested, daily use |
| Other Fire TV devices (Fire OS 7 and newer) | Expected to work, not tested |
| Android TV and Google TV devices (Android 9, API 28, or newer) | Checked on an Android TV emulator: Home, Settings, Search, Control Center, the output picker, Downloads and pairing run without errors, and Fire-only features are hidden. Not yet tested on real hardware |

Needs a TV with a remote (no touch or mouse support). Some Google TV and Chromecast firmware keeps its own launcher in front, so
Glass may not be able to become the default home there.

## Install (plain APK, no root)

1. Download `glass-tv-launcher-<tag>.apk` from the release page.
2. Install it one of two ways:
   - **On the TV with Downloader:** open the Downloader app, enter the APK's release-page address, and install when asked. Allow
     "Install unknown apps" for Downloader if the TV asks.
   - **From a computer with adb:** enable ADB debugging on the TV, then
     ```bash
     adb connect <tv-ip>:5555
     adb install -r glass-tv-launcher-<tag>.apk
     ```
3. Open Glass TV Launcher once from the TV's app list. The first launch shows a Welcome card (select Get Started). It may then
   show two more cards: "Turn on remote buttons?" and "Make Glass your Home". Select Cancel on both for now; the steps below
   cover them.
4. Make it your home screen. Glass's own Settings are not the big Settings tile: select the clock at the top right to open Control
   Center, then choose Launcher Settings (the sliders icon), then Home Button.
   - **Android TV / Google TV:** choose *Make Glass TV Launcher the Default*, pick Glass TV Launcher in the dialog Android shows,
     and select *Set as default*.
   - **Fire TV:** Fire OS has no default-launcher picker. Turn on *Home Button Takeover* on the same page, or see the README for the
     adb command. Keep the undo command at hand.
5. Optional one-time permissions (recent apps, Wi-Fi name, screensaver) are listed in the README. Everything works without them.

To go back: Settings → Home Button → switch the default home to the stock launcher, then uninstall Glass.

## What is in this beta

- Dock, folders, rearranging, hiding apps, icon packs and wallpapers (light and dark).
- Featured shelf from Stremio, Netflix, Prime Video, Disney+, Max, Hulu, YouTube or Plex, with an info panel and a Seasons view;
  Resume starts playback in the app (Stremio resumes with no extra press).
- Search across your apps, titles and music, with a full keyboard, a symbols page and forgiving matching.
- Control Center: Wi-Fi, Bluetooth, sleep, audio output picker (including network speakers), Do Not Disturb, Now Playing with seek and
  like, and Remotes and Game Controllers pages with pairing, a live controller tester and button mapping.
- A Control Center shortcut on a remote key, and remappable remote and controller buttons.
- Install and update progress on app tiles, and a "View in Store" shortcut.
- Notices that queue one at a time and hold under Do Not Disturb.
- Screen-reader labels on every control, Reduce Motion, Reduce Transparency and large text.
- In-app updates, backup and restore.

## Known limits

- Tested on real hardware only on a Fire TV Stick 4K (2nd gen). Everything else is untested or emulator-tested.
- English only.
- The in-app updater only looks at full releases, so a beta is installed by hand and will not offer itself as an update.
- Fire-only features (Alexa and Smart Home tiles, Amazon Appstore shortcuts) are hidden on other devices.
- Features that need root (Continue Watching rows from other apps, memory tuning, system-app mode) appear only on rooted devices and
  are off otherwise. Remote buttons that Fire OS keeps to itself need the optional key-layout module and a rooted Fire TV.
- Pairing from Glass needs Bluetooth permission. Where the system does not let Glass scan, the Pair page opens the system Bluetooth
  settings instead.
- The aerial screensaver streams from an undocumented online feed, and streaming availability comes from an unofficial endpoint.
  Either can change or stop working without notice.
- The release is signed with the project's release key; builds from source are signed with a debug key, so you cannot install one
  over the other without uninstalling first.

## Reporting bugs

Open an issue at <https://github.com/AazainKhan/glass-tv-launcher/issues> with:

- your TV or stick model and its Android or Fire OS version,
- the Glass version (Settings → About),
- what you did, what you expected and what happened,
- a photo of the screen if it helps.

Security problems: see `SECURITY.md`, and do not post them publicly.
